### AI TOOLS USED IN LUNA

AI tools played a significant supporting role throughout the development of LUNA. 

1. **Google AI Studio**
   - Primary AI-assisted development environment.
   - Developing and improving the user interface and overall user experience.
   - Implementing features and integrating different components.

2. **ChatGPT**
   - For better prompt generation 
   - Refining our existing ideas
   - Code generation & Debugging

3. **Claude**
   - Planning the roadmap
   - Feasibility of code
   - Debugging

4. **Google Antigravity**
   - Assisting with development workflows.
   - Supporting code implementation, debugging, and refinement.
